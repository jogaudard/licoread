# makes df from 82z files compatible with fluxible

makes df from 82z files compatible with fluxible

## Usage

``` r
fluxible_82z(df, focus_gas)
```

## Arguments

- df:

  input dataframe from
  [licoread](https://jogaudard.github.io/licoread/reference/licoread.md)

- focus_gas:

  gas to select

## Value

an unnested df with only the selected gas
